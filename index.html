under the hood

How it works

Four steps run continuously in the background — light enough that a 30ms poll never costs you anything.

STEP 01

Poll

The script checks the cursor position every 30ms.

STEP 02

Detect the edge

Each machine is configured as TOP, BOTTOM, LEFT, or RIGHT — switching triggers on the opposite edge.

STEP 03

Dwell

The cursor must linger at the edge for ~567ms, shown as a progress-bar OSD, so a stray brush never switches you.

STEP 04

Jump

A HID++ "change host" command fires to the receiver, and the cursor re-centers on the other side with a confirmation.

mouse jumper pro

Built for real multi-PC desks

The Pro build layers power-user features on top, in both AutoHotkey v1.1 and v2.0, kept in sync.

Tray menu control

Reconfigure, pause/resume, switch now, open the folder, reload, or exit — all from a right-click, no hotkeys to collide with.

Any edge

Top, bottom, left, or right — pick whichever edge matches how your monitors actually sit on the desk.

Multi-monitor aware

Bind edge detection to one specific display's bounds instead of the whole virtual desktop.

Optional logging

Flip on EnableLogging to record every switch and warning to a plain-text log file.

Startup checks

Warns via a tray notification if hidapitester.exe or the configured receiver isn't found.

Dwell-to-switch OSD

A rounded, always-on-top progress bar shows exactly how close you are to triggering a switch.

Zero extra hardware

Reuses the multi-host receiver you already own — no physical KVM switch box, no second set of cables.

AHK v1 & v2

Every script ships in both syntaxes and is kept in sync — run whichever runtime is already on the machine.

quick start

Up and running in a minute

Do this on both PCs, with the opposite edge on each.

  1. Clone the repoOnto each PC that shares the receiver.
  2. Run the setup helperChecks AutoHotkey, downloads hidapitester.exe, and offers a Startup shortcut.
  3. Launch the scriptUse the first-run OSD to pick this machine's Position and target Channel.
  4. Repeat on the other PCSame steps, opposite edge — TOP on one, BOTTOM on the other.
# clone
git clone https://github.com/vmynick/ahk-mouse-jumper.git
cd ahk-mouse-jumper
# one-time setup (AutoHotkey check, hidapitester.exe, Startup shortcut)
.\setup.ps1 -Script mouse_jumper_pro.ahk
# then just run the script — the first-run OSD walks you through
.\mouse_jumper_pro.ahk
